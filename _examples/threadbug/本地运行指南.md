# 本地运行指南 - 最简单的方法

## 🎯 三种方法（选一种即可）

### 方法 1: 克隆仓库（推荐）

```bash
# 1. 克隆仓库
git clone https://github.com/go-python/gopy.git

# 2. 进入目录
cd gopy/_examples/threadbug

# 3. 直接运行
go run demo_bug.go
go run demo_fixed.go
```

### 方法 2: 直接下载文件

```bash
# 1. 创建目录
mkdir -p ~/threadbug-demo
cd ~/threadbug-demo

# 2. 下载文件
curl -O https://raw.githubusercontent.com/go-python/gopy/main/_examples/threadbug/demo_bug.go
curl -O https://raw.githubusercontent.com/go-python/gopy/main/_examples/threadbug/demo_fixed.go

# 3. 运行
go run demo_bug.go
go run demo_fixed.go
```

### 方法 3: 手动创建文件

如果无法访问 GitHub，可以手动创建文件：

#### 创建 demo_bug.go

在你的电脑上创建文件 `demo_bug.go`，内容可以从 `GET_STARTED.md` 中复制。

或者使用这个简化版本：

```go
package main

import (
	"fmt"
	"runtime"
	"sync"
	"time"
)

func main() {
	fmt.Println("Bug 演示：goroutine 切换线程导致的问题")
	
	var wg sync.WaitGroup
	errors := 0
	
	for i := 0; i < 10; i++ {
		wg.Add(1)
		go func(id int) {
			defer wg.Done()
			
			// 模拟 PyGILState_Ensure (线程 T1)
			thread1 := getThreadID()
			fmt.Printf("Goroutine %d: Ensure on thread %d\n", id, thread1)
			
			// 危险：goroutine 可能切换线程
			runtime.Gosched()
			time.Sleep(time.Millisecond)
			
			// 模拟 PyGILState_Release (可能在线程 T2)
			thread2 := getThreadID()
			if thread1 != thread2 {
				fmt.Printf("❌ Goroutine %d: CRASH! Thread switched %d -> %d\n", id, thread1, thread2)
				errors++
			} else {
				fmt.Printf("✓ Goroutine %d: OK (same thread %d)\n", id, thread1)
			}
		}(i)
	}
	
	wg.Wait()
	fmt.Printf("\n结果: %d 个错误\n", errors)
}

var threadCounter int64
var mu sync.Mutex

func getThreadID() int64 {
	mu.Lock()
	defer mu.Unlock()
	threadCounter++
	return threadCounter
}
```

#### 创建 demo_fixed.go

```go
package main

import (
	"fmt"
	"runtime"
	"sync"
	"time"
)

func main() {
	fmt.Println("修复演示：使用 LockOSThread()")
	
	var wg sync.WaitGroup
	errors := 0
	
	for i := 0; i < 10; i++ {
		wg.Add(1)
		go func(id int) {
			defer wg.Done()
			
			// ✅ 锁定 goroutine 到当前线程
			runtime.LockOSThread()
			defer runtime.UnlockOSThread()
			
			// 模拟 PyGILState_Ensure (线程 T1)
			thread1 := getThreadID()
			fmt.Printf("Goroutine %d: Ensure on thread %d\n", id, thread1)
			
			// 安全：goroutine 被锁定，不会切换
			runtime.Gosched()
			time.Sleep(time.Millisecond)
			
			// 模拟 PyGILState_Release (仍在线程 T1)
			thread2 := getThreadID()
			if thread1 != thread2 {
				fmt.Printf("❌ Goroutine %d: ERROR! Thread switched %d -> %d\n", id, thread1, thread2)
				errors++
			} else {
				fmt.Printf("✓ Goroutine %d: OK (same thread %d)\n", id, thread1)
			}
		}(i)
	}
	
	wg.Wait()
	fmt.Printf("\n结果: %d 个错误 (应该是 0)\n", errors)
}

var threadCounter int64
var mu sync.Mutex

func getThreadID() int64 {
	mu.Lock()
	defer mu.Unlock()
	threadCounter++
	return threadCounter
}
```

## ✅ 运行步骤

无论用哪种方法，运行步骤都一样：

```bash
# 1. 确保在正确的目录
cd ~/threadbug-demo  # 或你的目录

# 2. 检查文件
ls demo_bug.go demo_fixed.go

# 3. 运行 Bug 版本
go run demo_bug.go

# 4. 运行修复版本
go run demo_fixed.go
```
